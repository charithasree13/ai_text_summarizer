# ai_text_summarizer
Description

This project is a web-based application that summarizes long text into short, meaningful content using Artificial Intelligence.
It also supports PDF file upload and ensures reliable output using a fallback summarization method.

Features
Text summarization
PDF upload and summarization
AI integration using HuggingFace API
Fallback mechanism (works even if API fails)
Simple user interface

Technologies Used
Frontend: HTML, CSS, JavaScript
Backend: Node.js, Express
API: HuggingFace
Libraries: axios, multer, pdf-parse
